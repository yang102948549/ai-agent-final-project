# 트레일러 영상 제작 PRD (`다른 곳의 하루`)

> 이 문서는 HyperFrames로 **「다른 곳의 하루」 트레일러 영상(약 1분 22초 MP4)**을 만들기 위한 제품 요구사항 정의서(PRD)다. 2026-11-27 콘티 v3.1을 검토한 뒤 v4로 다시 짰다.
>
> **v4에서 바꾼 것**
> - **길이:** 119.4초에서 **81.8초**로 줄였다(약 1분 20초).
> - **돌아보기:** 시오네 예시 대신 **아시프**로 맞춰 한 사람의 하루가 끊기지 않게 했다. 바로 뒤에 "이런 어려움을 겪는 다양한 사람들의 하루를 살아 볼 수 있다"는 장면(라마·암나·그라스 영상)을 넣었다.
> - **조사:** 질문을 던지면 AI가 자료를 찾아 답하는 모습을 넣었다(아시프).
> - **마지막 타이틀:** 「다른 곳의 하루」 위에 소제목으로 **도덕 · 인권 수업용**을 넣었다.
> - **줄인 장면:** 80초에 맞추려고 세 사람 소개는 아시프 한 명으로 줄였고, 인물 소개 화면·글 형식 고르기·갤러리 장면을 뺐다. 라마·암나 영상은 "다양한 사람들" 장면에서 쓴다.

> **B안:** 앱 장면의 주인공을 13살 학생 코피로 바꾼 안은 [TRAILER-PLAN-KOFI.md](TRAILER-PLAN-KOFI.md)에 있다. 두 안 중 하나를 골라 제작한다.

> **분량 주의:** 패들렛 채점 기준(`video/README.md`)은 트레일러를 **30~60초**로 적고 있다. 2026-11-27 사용자 결정으로 약 1분 20초로 만든다. 제출 전에 이 길이가 감점되지 않는지 확인한다.

## 1. 개요와 확정 결정

| 항목 | 명세 |
|---|---|
| **대상 앱** | 다른 곳의 하루 — 다른 나라 사람의 하루를 그 사람이 되어 살아 보는 웹앱 |
| **과제 평가 영역** | 트레일러 영상 15점 — *누구에게 무엇이 좋은 앱인지 전달되는지* |
| **분량·규격** | **81.8초** (`2,454 frames` @ `30fps`), `1920×1080`, H.264 `yuv420p` MP4 |
| **제작 도구·위치** | HyperFrames — 프로젝트 [`video/trailer/`](trailer/), 출력 `local-assets/video/trailer-v3.mp4` |
| **인물·장면 자료** | [characters.md](../app/design/characters.md), [scenario-branches.md](../app/design/scenario-branches.md), `local-assets/photoreal-characters/`, `local-assets/video/clips/` |

### 확정 원칙

1. **한 사람(아시프)의 하루를 따라가다가, 열두 사람으로 넓힌다.**
   - 처음: 여는 문장 → 아시프 → 12명 썸네일
   - 아시프의 하루(앱): 장면·대화 → 상황 → 선택지 → 웹앱에서 고르기 → 돌아보기 → 조사
   - 넓히기: 다른 어려움을 겪는 사람들(라마·암나·그라스) → 세 가지 글(서로 다른 인물의 글)
   - 끝: 웃는 시오네와 닫는 질문 → 12명 썸네일과 타이틀 → 페이드아웃
2. **12명은 사진 썸네일로 보여 준다.** 앱 화면 캡처를 쓰지 않는다. 처음(S3)에는 이름 · 나라 · 상황 한 줄(앱 속 인물별 이야기 제목)을 붙인다.
3. **앱 장면은 실제 사용 순서를 따른다.** 장면·대화 → 선택 → 돌아보기 → 질문·조사 → 글.
4. **선택은 세 단계로 보여 준다.** ① 상황 한 문장(글만) → ② “당신이라면 어떤 선택을 하시겠습니까?”와 A/B 선택지(글만) → ③ 실제 웹앱에서 같은 선택지를 눌러 결과로 넘어가는 모습.
5. **세 가지 글을 모두 보여 준다.** 신문 기사 → 정책 제안서 → 편지.
6. **문장**
   - 여는 문장: “오늘, 나와 다른 하루를 사는 사람들이 있습니다.”(검은 화면)
   - 앱 공개: “우리는 오늘 누군가의 하루를 대신 살아 봅니다.”
   - 닫는 질문: “내일, 우리들의 하루는 어떻게 될까요?”(웃는 시오네와 함께)
   - 대상은 마지막 타이틀 위 소제목 **도덕 · 인권 수업용**으로만 밝힌다.
7. **QR 코드·접속 주소·내레이션은 넣지 않는다.** 글꼴은 Pretendard 하나로 통일하고, 잔잔하고 간결하게 만든다.

## 2. 머무는 시간 규칙 (가독성)

| 규칙 | 기준 |
|---|---|
| 그림 먼저 | 컷이 바뀌면 0.3~0.5초 그림(또는 앱 화면)만 보여 준 뒤 글자를 띄운다 |
| 글자 머무는 시간 | **글자 수(띄어쓰기 포함) ÷ 8 + 1초**, 최소 2초 |
| 앱 장면 | 6초 이상. 확대가 끝난 뒤 1.5초 이상 멈춘다 |
| 한 컷 = 한 문장 | 위쪽 설명은 컷마다 한 문장(선택지 카드만 예외: 질문 + A/B) |
| 글자 자리 고정 | 인물 컷은 **왼쪽 글, 오른쪽 영상**. 앱 컷은 **위에 글, 아래에 앱 화면**. 글 카드는 **왼쪽 정렬, 세로 가운데** |
| 전환 | 0.3초 겹쳐 바꾸기만 쓴다. 마지막만 1.1초 페이드아웃. 빠른 컷·플래시·흔들림은 금지 |

### S1. 여는 문장 (0–4초)

- 검은 화면. `0.1초` “오늘,” · `0.27초` “나와 다른 하루를 사는 사람들이 있습니다.” (21자, 3.6초 머묾) · `3.85초` 글과 검은 화면이 함께 걷힌다.

### S2. 아시프 (4–8.8초)

- 인물 컷 배치. `0.4초` 사는 곳 **파키스탄 자코바바드** → `0.5초` 문장 **아시프는 아침부터 38도 더위 속에서 일합니다.**(22자, 4.0초 머묾)와 아시프 색 띠 → `4.53초` 글이 사라짐.

### S3. 12명 썸네일 (8.8–14.3초)

- 종이 바탕. `0.4초` 위쪽 문장: **우리는 오늘 누군가의 하루를 대신 살아 봅니다.** (21자, 4.9초 머묾)
- `0.4초`부터 12명이 4.2절 순서대로 0.08초 간격으로 나타난다(6열 × 2줄).
  - 사진: 268×260
  - 아래 글: **이름 · 나라**(28px 600), 상황 한 줄(28px 400 `#5c5c5c`, 최대 2줄)
- `1.4초`에 다 놓이고 3.3초 머문다. 이 장면에서는 모든 상황 한 줄을 다 읽지 못해도 된다. "서로 다른 열두 사람"이 한눈에 보이는 것이 목적이고, 이름과 나라는 읽힌다.
- `4.7초` 아시프를 뺀 11명이 0.5초에 걸쳐 30% 밝기로 흐려지고, 아시프 사진 테두리 2px `#2d6b63`이 생긴다 → S4로 0.3초 겹쳐 넘어간다.

### S4. 장면과 대화 (14.3–21.3초)

- REC-01: 아시프 낮 장면 「멈춰 버린 선풍기」. 본문이 보인다 → 답 칩 “어머니, 물 한 모금이라도 먼저 드세요.”를 누른다 → 학생 말이 오르고 어머니의 실제 AI 대답이 이어진다(기다리는 시간은 녹화에서 뺌).
- `0.6초` 장면 본문 쪽으로 1.6배 확대 → `3.6초` 대화 쪽(학생 말과 AI 대답)으로 옮겨 확대 → `4.4초`부터 멈춤.
- `0.4초` 문장: **그 사람이 되어 장면을 읽고, 주변 사람과 AI로 대화합니다.** (29자, 4.6초) → 끝까지(6.6초).

### S5. 상황 한 문장 (21.3–27.1초, 글 카드)

- 종이 바탕, 왼쪽 정렬. `0.3초` 작은 줄 **아시프의 낮**(32px `#5c5c5c`).
- `0.4초` 본문: **정전된 찜통 집에서 숨이 찬 어머니, 쉼터까지는 걸어서 30분입니다.** (34자, 5.25초 → 5.4초 머묾). 아래에 아시프 색 띠.
- 문장은 대본(「멈춰 버린 선풍기」 본문: 정전으로 찜통처럼 더운 집, 숨이 찬 어머니, 걸어서 30분 걸리는 쉼터)에 있는 사실만 쓴다.

### S6. 선택지 (27.1–35.1초, 글 카드)

- `0.3초` **당신이라면 어떤 선택을 하시겠습니까?** (52px)
- `0.9초` **A** 옆집에 어머니를 잠시 부탁한다 (40px, A는 아시프 색 네모 안 흰 글자 — 앱 버튼과 같은 모양)
- `1.4초` **B** 돈을 빌려 릭샤를 불러 쉼터로 모셔 간다
- 끝까지 머문다(질문 7.7초). 선택지는 앱 화면의 버튼 문구와 똑같이 쓴다.

### S7. 웹앱에서 고르기 (35.1–42.1초)

- REC-02: 실제 선택 화면. “아시프라면, 어떻게 할까요?”와 A/B 버튼이 보인다.
- `0.5초` A/B 버튼 쪽으로 1.8배 확대 → 커서가 A 위로 와서 `3.0초`에 누른다 → 결과 화면(「이웃의 배려와 빚진 마음」, 얻은 것·잃은 것)으로 넘어간다 → `3.8초` 결과 쪽으로 옮겨 1.5배 확대 → `4.6초`부터 멈춤.
- `0.3초` 문장: **웹앱에서는 이렇게 고릅니다.** → `3.6초` **선택에 따라 하루가 달라집니다.** → 끝까지(3.4초).

### S8. 돌아보기 (42.1–48.1초)

- REC-03: 아시프의 돌아보기 화면 “어려웠던 건, 선택만의 문제였을까요?” → 커서가 “무엇을 골라도 그대로였던 어려움” 칸을 누르고 **어느 쪽을 골라도 집은 정전으로 찜통이었다.**를 입력한다.
- `0.5초` 질문 제목과 입력 칸 쪽으로 1.5배 확대.
- `0.3초` 문장: **무엇을 골라도 바뀌지 않은 어려움을 찾습니다.** (23자) → 끝까지(5.7초).

### S9. 질문과 AI 조사 (48.1–54.6초)

- REC-04: 아시프의 질문·조사 화면. 질문 칸에 미리 쓴 질문(예: **자코바바드는 왜 이렇게 더워졌을까?**)을 보내면 AI 조사 도우미가 자료를 찾아 답하고, 답 아래에 직접 확인할 원문 자료가 붙는다(기다리는 시간은 녹화에서 뺌).
- `0.5초` 질문과 AI 답 쪽으로 1.6배 확대 → `4.0초`부터 멈춤.
- `0.3초` 문장: **궁금한 것을 물으면, AI가 자료를 찾아 답합니다.** (25자) → 끝까지(6.2초).
- 질문 문구는 녹화 전에 앱 화면에서 확정한다. AI 답과 자료가 장면에 맞는지 녹화 후 확인한다.

### S10. 다양한 사람들 (54.6–60.6초)

- 종이 바탕. 3:4 영상 세 개(각 480×640, 간격 40px)가 왼쪽부터 라마 → 암나 → 그라스 순서로 0.15초 간격으로 들어온다. 영상 아래에 **이름 · 나라**(28px 600)를 붙인다.
- `0.5초` 위쪽 문장: **열두 사람이 겪는 서로 다른 어려움을 살아 볼 수 있습니다.** (27자, 5.3초 머묾)
- 세 영상은 2%만 천천히 다가간다.

### S11. 세 가지 글 (60.6–70.8초)

| 구간 | 화면 | 위쪽 문장 |
|---|---|---|
| 60.6–64.0 | REC-05: 완성된 **신문 기사**(시오네)를 천천히 내려 봄 | 신문 기사로 알리고, |

### S12. 시오네와 닫는 질문 (70.8–76.3초)

### 7.2 앱 화면 녹화 (REC-01~07)

배포 사이트(`https://onischool.net/anotherday/`)를 `video/trailer/tools/record-app.mjs`(Playwright + Chrome 화면 전송)로 조작하며 녹화한다.
- **해상도:** 화면 1440×900, **deviceScaleFactor 2 → 2880×1800 프레임**. MP4는 2880×1800, CRF 16 이하.
- **위치:** 원본은 `local-assets/video/app-recordings/`, 쓰는 파일은 `video/trailer/assets/app/`(Git 제외).
- **길이:** 장면 길이보다 2초 이상 길게 녹화하고, 끝에 2초 이상 정지 구간을 둔다.

| 녹화 | 쓰는 곳 | 화면과 동작 | 데이터 |
|---|---|---|---|
| REC-01 | S4 | 아시프 낮 장면 → 답 칩 클릭 → 어머니의 AI 대답 | **실제 배포 AI** |
| REC-02 | S7 | 아시프 낮 선택 화면 → A 클릭 → 결과 | AI 미연결 상태 화면(선택지가 바로 보임) |
| REC-03 | S8 | 아시프 돌아보기에 바뀌지 않은 어려움 입력 | 예시 작성 |
| REC-04 | S9 | 아시프 질문·조사에서 질문을 보내고 AI 조사 도우미가 자료와 함께 답함 | **실제 배포 AI** |

| REC-06 | S11 | 정책 제안서 완성 화면(마리암) | 예시 작성본(`app/tools/gallery-mock.mjs` 글) |
| REC-07 | S11 | 편지 완성 화면(코피) | 예시 작성본(`app/tools/gallery-mock.mjs` 글) |

- **개인정보:** 실제 학생 정보, API 키, 교사 비밀번호가 화면에 나오지 않게 한다. 예시 이름은 가린 형태(`김*늘`)만 쓴다.

## 9. 검수 기준

1. **규격**: 81.8초, `1920×1080` MP4가 정상 재생된다. 마지막 프레임은 검은 화면이다.
2. **처음 보는 사람 기준**: 소리를 끄고 한 번 본 사람이 다음 다섯 가지를 말할 수 있다.
   - ① 다른 나라 사람의 하루를 그 사람이 되어 살아 보는 앱이다.
   - ② 아시프가 어떤 상황에서 무엇을 고르는지, 앱에서 어떻게 고르는지 안다.
   - ③ 비슷한 어려움을 겪는 다른 사람들(열두 명)의 하루도 살아 볼 수 있다.
   - ④ 대화하고, 돌아보고, AI에게 물어 조사하고, 기사·정책 제안서·편지를 쓴다.
   - ⑤ 도덕 · 인권 수업용 앱 「다른 곳의 하루」다.
3. **선명도**: 썸네일의 이름·나라와 확대 구간의 앱 글자가 렌더한 MP4에서 읽힌다.
4. **속도**: 모든 문장이 2절 규칙만큼 머문다. 처음부터 끝까지 재생해 "보려는데 넘어가는" 장면이 없다. S3 상황 한 줄은 다 읽지 못해도 되는 것으로 한다.
5. **결함 0건**: 글자 잘림·겹침·안전 여백 침범이 없다. AI 기본 디자인 요소가 없다.
6. **안전**: 실제 학생 정보·API 키가 보이지 않는다. 음원 출처를 기록한다.

2. **(다음)** 앱에서 아시프의 질문·조사 화면과 질문 문구를 확인한다. `record-app.mjs`를 2배 해상도와 REC-01~07로 고쳐 녹화하고, 하나씩 열어 확인한다(선명도, 동작, 개인정보, 문구 대조, AI 대답).
3. `prepare-assets.sh`에 썸네일 12장과 S10 영상 세 개, 시오네 끝 프레임을 더한다. `build-scenes.mjs`에 장면 13개와 확대 위치를 넣어 만든다.
4. `hyperframes check`와 스냅숏으로 검토하고 `local-assets/video/trailer-v3.mp4`로 렌더링한다. 처음부터 끝까지 재생해 확인한다.
5. 음원이 정해지면 배경 음악과 클릭 소리를 넣는다. 제출 길이 기준(30~60초)을 다시 확인한다.
