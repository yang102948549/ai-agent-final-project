# 트레일러 영상 제작 PRD (`다른 곳의 하루`)

> 이 문서는 Remotion으로 **「다른 곳의 하루」 트레일러 영상(30~60초 MP4)**을 제작하기 위한 제품 요구사항 정의서(PRD)다. 기획 의도, 확정된 연출 원칙, 프레임 단위 스토리보드, 추가 캡처 명세, Remotion 코드 구조, 검수 기준을 하나로 고정한다.

---

## 1. 프로젝트 개요 및 확정 결정사항

| 항목 | 명세 |
|---|---|
| **대상 앱** | **다른 곳의 하루** (`https://onischool.net/anotherday/`) |
| **과제 평가 영역** | 트레일러 영상 **15점** — *누구에게 무엇이 좋은 앱인지 1분 안에 전달되는지* (‘깎음’ 수준 목표) |
| **목표 분량·규격** | **54초** (`1,620 frames` @ `30fps`, `1920×1080` 16:9 FHD, H.264 `yuv420p` MP4) |
| **제작 도구·저장 위치** | **Remotion** — 제작 코드 `video/`, 최종 출력 `local-assets/video/trailer.mp4` |
| **참고 자료** | 발표 슬라이드 [moral-ai-class-1112](https://github.com/yang102948549/moral-ai-class-1112) (27장), 배포 앱 [app/](../app/), 시나리오 정리 [scenario-branches.md](../app/design/scenario-branches.md) |

### 확정된 3대 제작 원칙

1. **인물 연출 — 여러 인물 교차(Multi-Character Intercut)**
   - 단일 인물 소개에 머무르지 않고, **12개국·지역 또래 중 핵심 인물들을 교차 편집**해 환경·물·빈곤·난민·인권 주제의 폭과 선택별 장면 변화를 입체적으로 전달한다.
2. **사운드 — 안 A (타이포/자막 중심 + 잔잔한 BGM + 절제된 효과음)**
   - 음성 내레이션 없이도 **무음 재생 상태에서 100% 이해**되도록 화면 카피를 짧고 선명하게 설계하고, 에디토리얼 톤의 잔잔한 BGM과 절제된 전환/UI 효과음으로 리듬을 만든다.
3. **에셋 전략 — 기존 배포 캡처 + 라이브 추가 캡처 4컷 도입**
   - 이미 확보된 실사 캐릭터·장면·히어로 앨범·돌아보기 캡처에 더해, 라이브 사이트(`onischool.net/anotherday/`)에서 **AI 대화 칩·조사 응답/출처·완성 결과물/피드백·학급 갤러리** 4컷을 공개 가능한 예시 데이터로 추가 촬영해 실제 동작(API + DB)까지 증명한다.

## 2. 타깃 시청자와 핵심 메시지

### 타깃 시청자

- **1차 타깃 (현장 사용자)**: 중학교 도덕 「지구촌 문제」(성취기준 `9도03-03`) 수업을 운영하는 **교사**와 휴대폰·태블릿·PC로 참여하는 **학생**.
- **2차 타깃 (평가자)**: 1분 안에 **대상 사용자·수업 효용·AI 기본 디자인 탈피(‘깎음’)·실제 배포 기능(AI API + 갤러리 DB)**을 확인하는 심사자.

### 1분 안에 반드시 전달할 3가지 가치

1. **즉시 진입하는 3차시 수업 도구**: 설치·로그인·이름 입력 없이 바로 인물의 하루로 들어가며(PC·모바일 반응형), 1차시 체험 → 2차시 조사 → 3차시 글쓰기·공유까지 한 흐름으로 이어진다.
2. **정답을 대신 쓰지 않는 AI의 3역할**: AI가 **대화 상대**(인물 주변 사람) → **조력자**(원문 근거 안내) → **피드백**(인물·선생님의 되물음) 역할을 맡아 학생 스스로 판단하게 한다.
3. **선택이 실제로 바꾸는 하루와 현장감**: 12명 실사 인물, 8명 선택별 장면 갈래, 35장 상황별 현장 이미지, 20자 문장 틀, 3종 문서 서식(기사·정책 제안서·편지)과 학급 갤러리.

AI 기본 템플릿(보라 그라데이션, 네온 글로우, 가운데 큰 제목+시작 버튼, 이모지 카드)을 배제하고, 앱과 발표 슬라이드(`moral-ai-class-1112`)가 공유하는 **인쇄된 현장 보고서(르포 매거진)** 톤을 통일 적용한다.

| 요소 | 토큰·규격 | 비고 |
|---|---|---|
| **배경·잉크** | `#ffffff` (종이), `#f4f3ef` / `#e9e8e3` (보조 면), `#111111` (다크 씬·본문 잉크), `#5c5c5c` (보조 글자) | 씬 1(Hook)만 `#111111` 암전, 이후 밝은 르포 톤 |

## 5. 프레임 단위 스토리보드 (총 54초 · 1,620 frames @ 30fps)

### S1. Hook — 질문으로 여는 문제 제기 (`0:00–0:07` · `0–210f` · 7초)

- **목적**: 첫 7초 안에 “단순 지식 암기가 아니라 삶의 조건을 묻는 도덕 수업”임을 강하게 각인한다(발표 2·3·22장 계승).
- **화면 연출**:
  - `0–60f`: `#111111` 암전 바탕 오른쪽에 12명 얼굴 썸네일(`*-face.webp`) 4×3 격자가 은은하게 순차 점등(`Stagger`).
  - `30–110f`: 왼쪽에 Gowun Batang 질문이 줄 단위로 떠오름(`Rise`): *“새 학년이 시작됐는데 / 학교에 가지 않는 학생이 있습니다.”*
  - `115–210f`: 위 문장이 회색으로 물러나고, 중앙에 **“왜 안 갔니?”** 등장 → `145f`에 굵은 취소선(`Wipe`) → `155f`에 크림슨(`#a3303d`) 강조로 **“왜 못 갔니?”** 등장.
- **사용 에셋**: `AST-01` (12명 `*-face.webp`).
- **사운드 큐**: `0f` 잔잔한 피아노/앰비언트 도입, `145f` 종이 긋는 취소선 SFX, `155f` 낮은 울림 톤.

### S2. Reveal — 대상 사용자와 앱 공개 (`0:07–0:15` · `210–450f` · 8초)

- **목적**: 15초 안에 **누가(중학교 도덕 교사·학생)**, **무엇을(다른 곳의 하루)**, **얼마나 간편하게(설치·로그인·이름 입력 없이)** 쓰는지 명확히 전달한다.
- **화면 연출**:
  - `210–225f`: `#ffffff` 종이 배경으로 깔끔한 컷 전환.
  - `225–300f`: 상단 라벨 `중학교 도덕 · 지구촌 문제 해결 (9도03-03)` + 굵은 Pretendard 제목 **「다른 곳의 하루」** `Rise` 등장.
  - `270–450f`: 실제 배포 홈 화면(`AST-02`)을 데스크톱 프레임으로 띄우고, 우측 **12명 실사 히어로 사진 앨범**이 실제로 가로 이동하는 모션을 강조. 우하단에 모바일 홈 목업을 슬라이드 인 해 반응형 대응을 동시에 보여 준다.
- **화면 카피**:
  - 메인: **다른 곳의 하루** — *같은 하늘 아래, 전혀 다른 하루.*
  - 서브: *설치·로그인 없이 교실에서 바로 여는 3차시 수업 웹앱*
- **사용 에셋**: `AST-02` (배포 홈 PC·모바일 캡처 + `app/dist/assets/characters/*.webp` 앨범 트랙).
- **사운드 큐**: `210f` 부드러운 페이퍼 전환음 + BGM 본 리듬 진입.

### S3. Step 1 · 체험과 공감 — 여러 인물 교차 (`0:15–0:29` · `450–870f` · 14초)

1차시 핵심(“AI 대화 상대 + 선택이 하루를 바꾼다 + 35장 상황 이미지”)을 **3개 서브 컷**으로 속도감 있게 교차한다.

- **S3-A. AI 대화 상대 — 마리암 (`0:15–0:19` · `450–570f` · 4초)**
  - **연출**: 차시 배지 `1차시 · 체험과 공감`. 아프가니스탄 마리암(`#a3303d`)의 실제 라이브 AI 대화 화면(`CAP-01`) 표시. 학생 답 칩과 주변 인물 대사 말풍선을 순차 하이라이트.
  - **카피**: *AI가 정답을 대신 말하지 않습니다.* / **상황 속 인물이 되어 되묻습니다.**
  - **사운드 큐**: `480f`, `520f` 절제된 말풍선/칩 클릭 틱.
- **S3-B. 선택이 바꾸는 하루 — 시오네 분기 대비 (`0:19–0:25` · `570–750f` · 6초)**
  - **연출**: 투발루 시오네(`#1f7f7c`)의 아침 선택지 **A(시험 보러 감)** / **B(집에 남아 짐을 옮김)** 클릭 연출 → 화면이 좌우 2분할로 갈라지며 **낮 A 「떠날까, 남을까」**와 **낮 B 「보충 시험과 모래주머니」**(`AST-03`)가 나란히 대비됨. 우측 하단에 모바일 16:9 배너 컷 오버레이.
  - **카피**: **내 선택이 낮과 저녁, 장면까지 바꿉니다.**
  - **사운드 큐**: `600f` 버튼 선택 틱, `630f` 화면 분할 스와이프음.
- **S3-C. 4인 현장 몽타주 — 아시프·코피·그라스·라마 (`0:25–0:29` · `750–870f` · 4초)**
  - **연출**: 각 `30f(1초)` 간격으로 4명의 낮·저녁 상황별 실사 장면(`AST-04`)을 리듬감 있게 교차. 각 컷 하단에 인물의 고유 포인트 색 띠와 짧은 르포 캡션 표시:
    1. `750–780f` **아시프 · 파키스탄** — 「멈춰 버린 선풍기」 (정전 실내)
    2. `780–810f` **코피 · 가나** — 「밭에서 만난 아마」 (카카오 밭길)
    3. `810–840f` **그라스 · 콩고** — 「할머니의 무덤」 (철거 위기 가족 대화)
    4. `840–870f` **라마 · 팔레스타인** — 「급수차가 왔다」 (급수차 줄)
  - **카피**: **12명의 하루, 35장의 현장 장면으로 만나는 지구촌**
  - **사운드 큐**: `750f`, `780f`, `810f`, `840f` BGM 박자에 맞춘 가벼운 셔터/컷 틱.

### S4. Step 2 · 질문과 조사 (`0:29–0:38` · `870–1140f` · 9초)

- **목적**: 감상에서 끝나지 않고 **구조적 원인 성찰 → 근거 자료 검증**으로 이어지는 2차시 설계를 보여 준다.
- **S4-A. 돌아보기 — 시오네 (`0:29–0:33` · `870–990f` · 4초)**
  - **연출**: 차시 배지 `2차시 · 질문과 조사`. 실제 배포 돌아보기 화면(`AST-05`)을 띄우고, 질문 *“시오네가 무엇을 골라도 그대로였던 어려움은?”*과 **문장 틀 5개**(시설·돈·제도·안전·자연) 중 하나가 눌리며 실시간 글자 수(`20자 이상`)가 채워지는 포커스 확대.
  - **카피**: *개인의 선택을 넘어, 구조적 어려움을 내 문장으로 정리합니다.*
- **S4-B. AI 조사 도우미 & 원문 출처 — 마리암 (`0:33–0:38` · `990–1140f` · 5초)**
  - **연출**: 실제 라이브 질문·조사 화면(`CAP-02`)으로 전환. AI 조사 도우미 답변 아래 **`직접 확인해 볼 자료 · UNESCO`**와 펼쳐진 원문 출처 카드를 강조(발표 25장 구도 계승).
  - **카피**: **AI에게 묻고, 실제 원문 자료로 직접 확인합니다.**
  - **사운드 큐**: `900f` 칩 선택음, `1030f` 출처 카드 강조 톤.

### S5. Step 3 · 실천과 공유 (`0:38–0:47` · `1140–1410f` · 9초)

- **목적**: 3차시 결과물 글쓰기·피드백 대화(AI API)와 학급 갤러리 제출·공유(DB)를 한 호흡에 보여 준다.
- **S5-A. 3종 결과물 서식 (`0:38–0:41` · `1140–1230f` · 3초)**
  - **연출**: 차시 배지 `3차시 · 실천과 공유`. **신문 기사 · 정책 제안서 · 편지** 3가지 형식 카드가 부채꼴/가로 슬라이드로 전개된 뒤, 예시로 작성된 완성 서식(`CAP-03`)으로 포커스.
  - **카피**: *기사 · 정책 제안서 · 편지 — 내 목소리로 쓰는 해결책*
- **S5-B. 인물·선생님 피드백 대화 (`0:41–0:44` · `1230–1320f` · 3초)**

## 9. 검수 기준 (Acceptance Criteria — ‘깎음’ 체크리스트)

1. **규정 준수**: 길이 `30~60초`(목표 54초), `1920×1080` MP4 정상 재생, 모든 제작 코드가 `video/`에 커밋됨(MP4 본체는 `local-assets/video/`).
2. **메시지 명확성**: 소리를 끄고 처음 보는 시청자가 1분 안에 **대상 사용자(중학교 도덕 교사·학생)**와 **앱의 핵심 효용(AI 대화·선택 분기·근거 조사·피드백·갤러리)**을 설명할 수 있음.
3. **디자인 완성도**: 보라 그라데이션·네온·이모지 카드 등 AI 기본 템플릿 요소 0건. 앱·발표 슬라이드와 동일한 르포 매거진 톤 유지.
4. **시각 결함 0건**: 모든 씬에서 글자 잘림·겹침·안전 여백 침범 없음. 12명 및 교차 인물 실사 이미지의 얼굴·핵심 소품이 크롭으로 잘리지 않음.
5. **개인정보·저작권 안전**: 실학생 개인정보·API 키·교사 비밀번호 노출 0건. AI 가상 인물 안내 유지, 음원 출처(`SOURCES.md`) 명시.
