# 트레일러 영상 초안 틀 (`다른 곳의 하루`)

- **대상 앱**: **다른 곳의 하루** (`https://onischool.net/anotherday/`)
- **평가 영역**: 트레일러 영상 15점 — *누구에게 무엇이 좋은 앱인지 1분 안에 전달되는지* (‘깎음’ 수준 목표)
- **권장 분량**: **52초** (1920×1080, 30fps, 1,560 frames — 규정 30~60초 범위 내 여유 확보)
- **제작 방식**: Remotion (`video/src/trailer/`), 완성 MP4는 `local-assets/video/trailer.mp4`로 출력
- **핵심 참고 자료**: 발표 슬라이드 저장소 [moral-ai-class-1112](https://github.com/yang102948549/moral-ai-class-1112) (`도덕 수업, AI를 어떻게 쓸까` 27장) 및 현재 배포판 앱([app/](../app/))

## 1. 핵심 메시지와 대상 사용자

| 항목 | 내용 |
|---|---|
| **대상 사용자** | 중학교 도덕 「지구촌 문제」(성취기준 `9도03-03`) 수업을 진행하는 **교사**와 휴대폰·태블릿·PC로 참여하는 **학생** |
| **해결하는 문제** | 기존 수업은 교과서·통계를 읽고 답을 적어 내면 끝나 공감이 얕고, AI를 그냥 쓰면 정답을 대신 받아 적는 데 그친다. |
| **앱의 쓸모 (차별점)** | AI가 정답을 대신 써 주지 않는다. **12개국·지역 또래의 하루** 속에서 AI가 **대화 상대 → 조사 조력자 → 글쓰기 피드백** 세 역할을 맡아, 학생 스스로 **공감하고·근거를 확인하고·해결책을 제안**하도록 이끈다. |
| **한 줄 슬로건** | **“체험에서 공감으로, 공감에서 책임으로.”** / *“나의 생각을, 대화를 통해 정리하여 판단할 수 있게 한다.”* |

## 2. 비주얼·모션 방향 (발표 슬라이드 + 앱 르포 매거진 톤 계승)

AI 기본 템플릿(보라 그라데이션, 네온 글로우, 가운데 큰 제목+시작 버튼, 이모지 카드)을 완전히 피하고, 앱과 발표 슬라이드(`moral-ai-class-1112`)가 공유하는 **인쇄된 현장 보고서(르포 매거진)** 톤을 그대로 영상으로 확장한다.

- **색상 체계**:
  - 밝은 본문 바탕 `#ffffff`, 종이 보조 면 `#f4f3ef` / `#e9e8e3`, 본문 잉크 `#111111`
  - 질문·도입 암전 씬 `#111111` + 흰 글씨 `#ffffff`
  - 포인트 색: 인물의 고유 색 (`TONE` — 마리암 크림슨 `#a3303d`, 시오네 틸 `#1f7f7c`, 코피 브라운 `#86552a`)
- **서체**:
  - **Pretendard** (제목·차시 라벨·UI 설명·주소)
  - **Gowun Batang** (핵심 질문·인물 이름·대사·슬로건)
- **모션 언어** (`moral-ai-class-1112` 슬라이드 연출 계승):
  - `Rise` (줄 단위 mask 떠오르기), `Wipe` (왼쪽→오른쪽 펼치기), `Stagger` (카드·칩 순차 등장), **취소선 전환**(~~“왜 안 갔니?”~~ → **“왜 못 갔니?”**)
- **무음 재생 대응**: 심사 환경에서 소리를 끄고 봐도 100% 이해되도록 **핵심 카피는 화면 타이포그래피로 굵고 짧게** 배치한다(한 컷당 1~2줄, 20자 내외).

### Remotion 구현 전 추가 캡처하면 완성도가 크게 올라가는 컷 (3~4장)

1. **AI 대화 칩 활성 화면 (S3)**: 실제 라이브(`onischool.net/anotherday/`)에서 AI가 연결된 상태의 대화 말풍선 + 답 칩(`→` 결정 칩 포함) 1컷 (아프가니스탄 마리암 또는 투발루 시오네).
2. **질문·조사 AI 응답 + 원문 출처 열림 화면 (S4)**: AI 조사 도우미가 답하고 `직접 확인해 볼 자료`·`자료 열어 보기`가 펼쳐진 1컷.
3. **완성 결과물 서식 + 피드백 대화 화면 (S5)**: 예시 데이터로 채운 **정책 제안서** 또는 **신문 기사** 완성 화면 1컷 + 인물/선생님 피드백 대화 1컷.
4. **학급 갤러리 보드 화면 (S5)**: 공개 가능한 예시 결과물 3~4장이 카드로 쌓인 갤러리 보드 1컷 (실명 대신 `김*수` 가림 예시 확인 — **DB 가산점 시각 증거** 겸용).

## 5. 사운드·내레이션 옵션 (구현 전 결정 사항)

트레일러 착수 전 아래 두 가지 중 하나를 확정한다.

- **안 A (추천 · 자막 + 잔잔한 BGM + 절제된 효과음)**:
  - 다큐멘터리·에디토리얼 톤의 피아노/앰비언트 무료 BGM(저작권 표기 가능 음원) + 버튼 클릭·장면 전환·취소선 사운드.
  - 타이포그래피와 화면 전환 리듬에 집중하며, 소리 없이 봐도 어색함이 없다.
- **안 B (안 A + 짧은 음성 내레이션)**:
  - 교사 직접 녹음 또는 차분한 한국어 TTS로 6개 씬 각 1문장씩(총 5~6문장, 약 45초 분량) 얹고, BGM 볼륨을 낮춤.
