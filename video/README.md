# 제출 영상

두 영상은 모두 Claude 또는 Codex로 코드를 작성해 제작하며(수업 시연 도구: Remotion), 제작 코드를 이 `video/` 폴더에 함께 커밋한다. 영상 코드가 `video/`에 없으면 영상 하나마다 5점이 감점된다.

- **만든 과정 소개 영상 (2~3분, MP4)** — 고치기 전/후 비교 3번 이상, 바꾼 이유, AI에게 실제로 시킨 말을 보여준다.
- **트레일러 영상 (30~60초, MP4)** — 누구에게 무엇이 좋은 앱인지 1분 안에 전달한다.

캡처 원본, 렌더링 중간 파일과 완성 MP4는 먼저 `local-assets/`에 보관하고 직접 재생해 확인한다. 패들렛 제출 글에는 첨부 파일을 하나만 넣을 수 있으므로 영상 한 편은 글에 첨부하고, 다른 한 편은 자기 글의 댓글로 올린다. 완성 후 두 편의 재생·다운로드 링크를 루트 [README.md](../README.md)에도 남긴다.
