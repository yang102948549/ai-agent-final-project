# 상황별 장면 이미지 파일럿 설계·검증 기록

2026-11-25 · 시나리오 분기 재설계와 병행해 **상황별 장면 이미지 전환**과 **모바일 이미지 로딩 UX**를 먼저 검증하기 위한 파일럿 기록이다.

## 1. 파일럿 선정 기준

- 기존 캐릭터 이미지 12장(`dist/assets/characters/<id>.webp`)은 대표 프로필과 **아침(장면 1)** 상황에 잘 맞는다.
- 낮·저녁으로 시간과 장소, 갈래가 바뀌면 그 상황에 맞는 장면 이미지(`dist/assets/scenes/<key>.webp`)로 전환하고, 아직 전용 이미지가 없는 장면은 기존 캐릭터 이미지로 자연스럽게 폴백한다.
- 시나리오가 수정 중이므로, 재설계안([scenario-branch-plan.md](scenario-branch-plan.md))에서도 유지되는 확정 장면 위주로 파일럿을 구성했다.
  - **투발루 시오네 (분기 전환 검증 4장)**: 낮 A 「떠날까, 남을까」, 낮 B 「보충 시험과 모래주머니」, 저녁 AB 「할머니의 빵나무」, 저녁 BA 「선생님의 추천서」
  - **아프가니스탄 마리암 (아침→밤 실내 조명 연속성 검증 1장)**: 저녁 「사촌 언니의 전화」
  - *(보류 1장)* 마리암 낮 「이웃 언니의 귓속말」은 이미지 생성 서버 용량 제한(HTTP 503)으로 이번 파일럿에서는 미생성 상태이며, 기존 마리암 이미지로 폴백된다.

## 2. 공통 생성 원칙

- **기준 인물 참조**: `local-assets/photoreal-characters/<id>.png`를 참조해 얼굴·나이·옷차림·주제별 포인트 색을 동일하게 유지한다.
- **정면 초상 → 상황 스틸컷**: 카메라를 정면으로 응시하지 않고, 장면 속 상대방·소품·창밖을 바라보는 절제된 다큐멘터리 스틸컷으로 연출한다.
- **시간대 조명 분리**: 아침(기존) → 낮(강한 정오 햇빛·실내외 대비) → 저녁(노을·황혼·실내 등불·휴대전화 화면빛).
- **이중 비율 안전 구도**: 세로 3:4(896×1200)로 제작하되, 인물 얼굴과 핵심 행동이 상단~중앙에 오게 배치해 데스크톱 3:4 세로 카드와 모바일 16:9 가로 배너 모두에서 잘리지 않게 한다(`app.js`의 `SCENE_ART` 매핑에서 `pos`로 초점 위치 보정).
- **가이드라인 준수**([characters.md](characters.md)): 울음·상처·잔해·무기·아동 위험 노동 금지, 종이·칠판·휴대전화 화면에 읽히는 글자·로고·국기·기관 상징 금지.

## 4. 모바일 로딩 최적화 설계

1. **첫 화면(히어로) 선로딩**: `index.html`에 `<link rel="preload" as="image" fetchpriority="high">`를 추가해 스크립트 해석과 동시에 히어로 이미지를 받는다. 모바일(`≤900px`)은 실제 노출되는 2장(`bangladesh`, `ghana`)만 먼저 받고, `tuvalu`·`gaza`는 `media="(min-width:901px)"`로 데스크톱에만 선로딩한다.
2. **레이아웃 흔들림·글자 깜빡임 제거**: `.art`가 로딩되는 동안 거대한 첫 글자가 먼저 보이지 않도록 오류 시(`.is-error`)에만 첫 글자를 표시하고, 로딩 중에는 은은한 톤 쉬머를 둔다. 완료된 주소는 `loadedSrc`에 기록해 대화 중 재렌더링해도 깜빡이지 않는다.
3. **캐릭터별 지연 프리로드 + 전환 화면 대기**: 첫 화면 직후 전체 장면 이미지를 한꺼번에 받지 않고, 캐릭터 소개(`intro`)에 들어올 때 해당 인물의 상황 그림만 미리 받는다(`preloadCaseScenes`). 장면 전환(`dayPass`)이 진행되는 동안 다음 장면 그림의 디코드 완료를 최대 1.5초 한도로 기다려, 전환이 걷힐 때 글과 그림이 동시에 나타난다.
4. **모바일 16:9 고정 배너**: 기존에 모바일에서 숨겨져 있던 장면 이미지를 `.scene-card` 본문 맨 위에 `aspect-ratio: 16/9`(최대 높이 220px)로 고정 배치해, 장면 진입 시 상황을 바로 보고 대화를 스크롤하면 자연스럽게 위로 올라가도록 구성했다.

## 5. 전체 확장 절차 (파일럿 승인 후)

- 47장면 기준 아침 12장 유지 + 파일럿 5장 완료 → 나머지 30장(보류된 `afghanistan-noon` 포함)을 캐릭터별로 순차 생성한다.
- `app.js`의 `SCENE_ART`(또는 각 장면 객체의 `img`·`pos`)에 등록하면 자동 반영되며, `node validate.cjs`가 이미지 파일 존재 여부를 함께 검사한다. 시나리오 대본 파일(`scenarios.js`)과 분리해 두어 시나리오 편집 작업과 충돌하지 않는다.
